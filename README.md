# realalign.ai

One page for people who build AI and for AIs that read it. Part of Demismatch.
Plain static files: `index.html`, `llms.txt`, `style.css`, `fonts/`.
Serve the repo root as it is (GitHub Pages, branch main). The domain is set in `CNAME`.

`index.html` and `llms.txt` are written by a builder in the Demismatch workspace repo (`realalign/build.py`). Change the text there, never here.
